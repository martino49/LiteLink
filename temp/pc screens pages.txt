| **App Logo** | LiteLink logo (centered, large). |
| **App Name** | "LiteLink" (below the logo). |
| **Loading Bar** | A horizontal progress bar showing initialization progress. |
| **Status Text** | Shows: "Initializing..." → "Checking ADB..." → "Starting WebSocket server..." → "Ready". |
| **Version Number** | Shows app version at the bottom (e.g., "v1.0.0"). |
| **Auto-Transition** | After initialization completes, automatically transitions to the Dashboard Page (Page 4). |

**What happens during the splash screen:**
1. Checks if ADB and scrcpy binaries exist in the `bin/` folder.
2. Starts the WebSocket server on `0.0.0.0:8765`.
3. Loads saved settings from `config.json` or Windows Registry.
4. Attempts to auto-connect to the last known phone.
