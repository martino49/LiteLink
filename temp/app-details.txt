### 🎬 Animations
| Animation | Description |
| :--- | :--- |
| **Logo Fade-In** | Logo fades in over 800ms with a subtle scale-up (1.0 → 1.1 → 1.0). |

| **Status Text Fade** | Status text fades in/out when changing messages. |

### 🖱️ User Interactions
| Action | Result |
| :--- | :--- |
| **None** | This screen is passive. The user waits for 2-3 seconds while initialization completes. |
| **Tap (ignored)** | Taps are ignored during loading to prevent crashes. |

### 🔄 State Changes
| State | What Happens |
| :--- | :--- |
| **Loading** | Shows the loading animation and status text. |
| **Error (No Network)** | Shows a red error message: "No internet connection. Please connect to Wi-Fi." with a retry button. |
| **Error (No Permissions)** | Shows a yellow warning: "Permissions required. Grant access to continue." with a "Grant Permissions" button. |
| **Success** | After 2-3 seconds, automatically transitions to: |
| └─ **First Launch** | → **Onboarding Screen** (Screen 2). |
| └─ **Returning User** | → **Home Screen** (Screen 4). |

### 🧠 What Happens in the Background
1. Loads saved settings from `SharedPreferences` (IP address, encryption key, paired devices).
2. Checks if the app has Notification Access permission.
3. Checks if the phone is connected to Wi-Fi.
4. Attempts to auto-connect to the last known laptop IP (if saved).
5. Logs the initialization status for debugging.
